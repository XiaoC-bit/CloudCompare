# 第二部分：运动学基础（坐标系统扩展）

本部分用于建立多坐标系系统的运动学表达方式。

核心约束：

* 所有运动统一表示为 SE(3) 变换链
* 机床/机器人系统统一视为串联刚体系统
* 运动学问题统一分为 FK / IK 两类

---

## 4. 工业运动学基础（正运动学）

### 4.1 关节空间与笛卡尔空间

工业系统存在两种状态描述空间：

| 空间    | 描述对象   | 表达方式      |
| ----- | ------ | --------- |
| 关节空间  | 轴位置/角度 | q ∈ ℝⁿ    |
| 笛卡尔空间 | 位姿     | T ∈ SE(3) |

正运动学定义为：

```id="fk_def"
FK: q → T
```

即从关节变量映射到末端位姿。

---

### 4.2 变换链模型（多轴系统）

工业机床/机器人可建模为串联 SE(3) 变换链：

```id="chain_model"
T_total = T₁ · T₂ · ... · Tn
```

典型五轴结构可抽象为：

```
Base
  ↓ T_B
B axis
  ↓ T_C
C axis
  ↓ T_W
Workpiece
  ↓ T_T
Tool
  ↓ T_S
Sensor
```

整体位姿表达：

```id="fk_chain"
T_WS = T_B · T_C · T_W · T_T · T_S
```

---

### 4.3 轴旋转与绕点变换

B/C 轴本质为绕固定轴旋转，且存在旋转中心偏置。

绕点旋转统一表示为：

```id="rotate_point"
T(pivot, R) = T(pivot) · R · T(-pivot)
```

代码结构对应：

```cpp id="bc_chain"
return T(center)
     * T(R)
     * T(-center);
```

工业含义：

* 轴运动 ≠ 原点旋转
* 必须显式建模旋转中心偏置

---

### 4.4 DH 参数与工程建模差异

DH参数标准形式：

```id="dh"
T_i = Rot(Z, θ_i) · Trans(Z, d_i) · Trans(X, a_i) · Rot(X, α_i)
```

参数含义：

| 参数 | 物理意义 |
| -- | ---- |
| a  | 连杆长度 |
| α  | 连杆扭角 |
| d  | 轴向偏移 |
| θ  | 关节变量 |

工程上差异点：

| 方法     | 特征           |
| ------ | ------------ |
| DH建模   | 统一规则，适合机器人理论 |
| 旋转中心建模 | 直接基于机床结构     |

本项目采用：

* 显式旋转中心
* 避免DH参数拟合误差
* 更贴近机床几何结构

---

## 5. 逆运动学与误差传播（工程视角）

### 5.1 IK问题的非唯一性

逆运动学定义：

```id="ik"
IK: T → q
```

但满足：

* 多解存在（姿态冗余）
* 存在不可解区域
* 存在奇异位形

---

### 5.2 5轴机床姿态分解

旋转分解结构：

```cpp id="rot_decompose"
R = R_B · R_C
```

分解过程本质：

* 从 SO(3) 投影到轴参数空间
* 通过三角函数恢复轴角

典型提取方式：

```cpp
rz = atan2(R(1,0), R(0,0));
Rb = R · Rcᵀ;
ry = atan2(Rb(2,0), Rb(0,0));
```

该过程隐含约束：

* 轴顺序固定
* 变换链不可交换

---

### 5.3 奇异性（万向锁）

当 B 轴接近 ±90°：

```id="singularity"
sin(B) → 0
```

导致：

* C轴与主轴自由度耦合
* 旋转分解不唯一

处理策略：

```cpp id="gimbal_lock"
if (|sin(b)| < ε) {
    a = 0;
    c = atan2(-R(0,1), R(0,0));
}
```

本质：

* 降维约束解空间
* 引入人为自由度分配规则

---

### 5.4 数值求解方法

解析解不可用时，采用数值优化：

| 方法                     | 特点        |
| ---------------------- | --------- |
| Newton                 | 收敛快，但依赖初值 |
| Gradient               | 稳定但慢      |
| Jacobian Pseudoinverse | 工业常用      |

标准形式：

```id="jacobian"
Δx = J⁺ · (T_target - T_current)
```

关键约束：

* 避免奇异 J
* 控制步长
* 限制关节边界

---

### 5.5 误差传播模型

误差在 SE(3) 链中传播：

```id="error_chain"
δT_total ≈ Σ δT_i
```

工业系统表现为：

```
测量误差 → 标定误差 → 运动误差 → 执行误差
```

误差特征：

* 非线性累积
* 各轴耦合放大
* 旋转误差影响平移误差（通过叉乘项）

---

### 5.6 工程误差度量

残差定义：

```cpp id="residual"
res = Ax - b
```

统计量：

* RMS误差
* 最大残差
* 残差分布

```cpp
rms = sqrt(res.norm² / N)
max = max(|res_i|)
```

---

### 5.7 误差来源分解

| 来源    | 类型   | 影响   |
| ----- | ---- | ---- |
| 传感器噪声 | 随机误差 | 点云扰动 |
| 标定误差  | 系统误差 | 坐标偏移 |
| 机械精度  | 重复误差 | 轨迹偏差 |
| 热变形   | 时变误差 | 慢漂移  |
| 算法误差  | 数值误差 | 收敛偏差 |

## 小结

本部分建立工业运动学表达体系：

* FK：关节 → 位姿
* IK：位姿 → 关节（多解问题）
* SE(3)：统一运动表达
* 变换链：系统级建模方式
* 奇异性：结构性不可解区域
* 误差传播：系统级误差放大机制

该层模型是后续 ICP、RTCP、手眼标定与机床补偿算法的结构基础。
